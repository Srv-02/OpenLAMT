- MCP server: the new openlamt-mcp lets Claude and other AI agents run your devices
- Find Intel AMT devices with a network scan, and move your favorites to another computer with export and import
- Many new device pages: power and wake alarms, boot options, Wi-Fi, certificates, System Defense, audit settings, event forwarding and erasing drives
- Take screenshots of the remote screen, record it as a video and scale it to the window
- Check Intel AMT on the computer OpenLAMT runs on, and turn it on or activate it there (beta, Linux and Windows)
- Update with one click, and open the user guide in English or German from the question mark in the main window

## Fixed
- Cancelling a connection or a boot step no longer leaves changes behind on the device
- Sleeping devices are refused before anyone is asked for a consent code
- Accounts with limited AMT permissions can connect and see what they may read

## Notes
- macOS now comes as a disk image (.dmg), Linux also as an AppImage. The .zip for macOS is built one last time, so that older versions can still update.
- openlamt-mcp is a separate download on the Releases page.
- "This computer" uses a preview of Intel's rpc-go library. Turning on, activating and deactivating are not yet tested on many devices.
- The builds are not code-signed. macOS and Windows warn on the first launch; the README explains how to open the app anyway.
