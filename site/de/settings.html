App-Einstellungen und Updates

Diese Einstellungen gehören zu OpenLAMT auf deinem Computer. Sie ändern nichts an deinen Geräten. Die AMT-Einstellungen eines Geräts findest du auf seiner Seite „Einstellungen“.

Der Einstellungsdialog

Klicke auf das Schieberegler-Symbol neben Schnell verbinden unten in der Seitenleiste. Änderungen gelten, wenn du auf Speichern klickst. Abbrechen verwirft sie.

Allgemein

Sprache
Englisch oder Deutsch. System folgt deinem Computer. Die Sprache wechselt beim nächsten Start von OpenLAMT.
Erscheinungsbild
Hell, Dunkel oder System. System folgt deinem Computer, auch während OpenLAMT läuft.
Farbenblind-Modus
Statusfarben, die bei Rot-Grün-Schwäche unterscheidbar bleiben, zum Beispiel die Statuspunkte der Favoriten.

Updates

Ist Nach Updates suchen eingeschaltet, fragt OpenLAMT bei jedem Start GitHub, ob es ein neueres Release gibt. Jetzt prüfen fragt sofort, auch wenn der Schalter aus ist. Die Zeile zeigt dann „Prüfe …“ und danach das Ergebnis: die neueste Version in Grün oder den Grund in Rot, zum Beispiel „GitHub antwortet nicht. Versuche es später erneut.“ Bei einer neueren Version öffnet sich das Update-Fenster.

Die Anfrage enthält kein Konto, kein Token und keine Daten über deine Geräte. GitHub sieht deine IP-Adresse.

Das Update-Fenster

Das Fenster zeigt die ersten Zeilen der Release Notes. Aktualisieren lädt die neue Version herunter und prüft sie gegen die SHA-256-Prüfsumme, die GitHub angibt. Später schließt das Fenster, auch während des Downloads. Danach beendet sich OpenLAMT auf dem normalen Weg (offene KVM-Sitzungen fragen vorher) und übergibt an dein System:

SystemWas „Aktualisieren“ tut
macOSÖffnet das neue Disk-Image im Finder und beendet sich. Zieh die neue App auf die alte.
WindowsErsetzt OpenLAMT.exe und startet die neue Version. In einem Ordner, in den nur ein Administrator schreiben darf, etwa Program Files, fragt Windows vorher nach der Berechtigung. Die alte Datei bleibt als OpenLAMT.exe.old liegen, bis die neue Version sie löscht.
Linux (.deb)Speichert das Paket in ~/Downloads, öffnet es von dort in deinem Software-Installer und beendet sich. Gibt es schon eine Datei mit diesem Namen, bekommt die neue eine Nummer, zum Beispiel OpenLAMT-1.3.0-linux-x64 (1).deb; nichts wird überschrieben.
Linux (AppImage)Lädt das neue AppImage herunter. Im Ordner zeigen zeigt es an; die alte Datei ersetzt du selbst.

Schlägt ein Schritt fehl, zum Beispiel weil du die Berechtigungsabfrage von Windows abgelehnt hast, bleibt das Paket in ~/Downloads, und das Fenster sagt dir, wie du es selbst installierst. Passt der Download nicht zu seiner Prüfsumme oder bricht er ab, meldet Update fehlgeschlagen das, und nichts wird installiert. Erneut versuchen beginnt von vorn.

Geräte

Abfrage-Intervall
Wie oft OpenLAMT den Energiezustand deiner Favoriten und der geöffneten Geräte liest, in Sekunden (1 bis 3600). Der Standardwert ist 10.

Fernbildschirm

KVM-Qualität
Hoch (65.536 Farben) oder Niedrig (256 Farben) für jedes Gerät ohne eigene Wahl. Niedrig braucht weniger Bandbreite.
KVM-Autoverbindung
Verbindet den Fernbildschirm, sobald sich ein Gerätefenster öffnet. Ein Favorit kann das überschreiben.
KVM trennen ohne Eingabe nach
Beendet eine Sitzung am Fernbildschirm nach so vielen Minuten ohne Tastatur- oder Mauseingabe, oder Nie. Der Standardwert ist 30 Minuten. AMT erlaubt eine KVM-Sitzung pro Gerät, ein vergessenes Fenster würde also andere blockieren.
Layout für Zwischenablage tippen
Das Tastaturlayout, das Zwischenablage tippen auf dem Gerät verwendet. Automatisch (Systemsprache) wählt das Layout deiner Systemsprache. Ein Favorit kann das überschreiben.
Screenshots und Aufnahmen
Der Ordner für Screenshots und Aufnahmen. Wählen… legt ihn fest, löscht die Angabe. Ohne Ordner fragt OpenLAMT jedes Mal nach einem Dateinamen.

Daten

Konfiguration
Exportieren… und Importieren… übertragen Favoriten und Einstellungen als Datei. Siehe Export und Import.
Ausgeblendete Hinweise
Hinweise zurücksetzen zeigt jede Meldung wieder an, die du mit „Nicht mehr anzeigen“ ausgeblendet hast.

Über OpenLAMT und Unterstützung

Über & Credits zeigt die Version und die Drittbibliotheken mit ihren Lizenzen. Unterstützen zeigt Wege, das Projekt zu unterstützen, etwa einen Stern auf GitHub oder einen Kaffee. OpenLAMT ist kostenlos und Open Source.
