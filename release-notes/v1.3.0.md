- MCP server: openlamt-mcp now scans the network and adds, edits and deletes favorites, also on Linux without a display and without the app
- Passwords for openlamt-mcp can come from a password manager or another command, bound to each device's host
- The app itself is unchanged in this version

## Notes
- New terminal commands: "openlamt-mcp password" stores a device password, "openlamt-mcp trust" pins a device certificate. The AI agent never sees the password.
- The builds are not code-signed. macOS and Windows warn on the first launch; the README explains how to open the app anyway.
