The device window

Each device opens in a window of its own. The toolbar holds power control, the remote screen, the serial console, media and device management.

Toolbar and status bar

The toolbar has four groups:

  1. Power: the Power menu.
  2. KVM and Console switch the view. Media, Quality and Scale belong to it.
  3. Input and capture: Ctrl+Alt+Del, Type Clipboard, Keyboard, Screenshot, Record.
  4. Manage opens device management. Full Screen fills the screen with the remote picture.

The status bar shows the power state, the AMT version, the control mode, whether the connection uses TLS, and the state of the remote screen. Messages about screenshots, recordings and media appear there as well.

Power menu

OpenLAMT reads the power state when you open the menu. Entries that do not fit the state are grey: a running device cannot be powered on, a device that is off only offers Power On, Reboot to BIOS… and Boot from ISO…. While the device sleeps, or its state is unknown, every entry is open. Entries with “…” ask first.

EntryWhat happensAsks
Power OnSwitches the device on.no
Power Off…Switches off at once, without shutting down the operating system. Unsaved data and running VMs are lost.simple
Reset…Restarts at once, without shutting down the operating system.simple
Power Cycle…Switches off and on again at once, without shutting down the operating system.simple
Reboot to BIOS…Restarts at once and opens the BIOS setup. A device that is off powers on into the BIOS.simple, none when the device is off
Boot from ISO…Restarts from the ISO you mounted under Media, once. Grey without a mounted image.question
Shutdown…Shuts the operating system down in an orderly way, then switches off.simple
Sleep…The operating system goes to sleep. The device stays reachable and wakes on request.simple
Hibernate…The operating system saves its memory to disk and switches off.simple

Shutdown… needs help from the operating system. AMT offers it only while the Intel management service (LMS) runs on the device. Sleep… and Hibernate… stay grey unless the device lists these power states. The Power page shows which states a device supports.

AMT refuses Power Off, Power Cycle and Shutdown while a remote screen session is open. OpenLAMT therefore closes the session first and connects again when the device is back.

Remote screen (KVM)

KVM shows the screen of the device and sends your keyboard and mouse to it. It works from the moment the device powers on, also in the BIOS and in the boot loader.

  • Click Connect KVM in the middle of the window. With KVM auto-connect on, the screen connects when the window opens.
  • If the device asks for user consent, enter the six-digit code from its screen.
  • When KVM connects, OpenLAMT presses a harmless key (F15) to wake a dark screen.
  • Quality switches between High quality (65,536 colors) and Low quality (256 colors). Low is faster on slow links.
  • OpenLAMT ends the session after a time without input. Set the time in Settings.
  • AMT allows one KVM session per device. If another tool holds it, the device refuses a second one.

Keyboard

Your computer keeps some key combinations for itself, for example Ctrl+Alt+Del, Cmd+Tab and, on Windows, Win+L. They never reach the device. Use the Ctrl+Alt+Del button to send that combination.

Type Clipboard

Type Clipboard types the text on your clipboard into the device, key by key. Use it for long passwords or commands, also in the BIOS or a console without copy and paste.

  • The device must use the keyboard layout you choose under Keyboard. OpenLAMT knows 16 layouts. Default uses the layout of the favorite or of the app setting.
  • Characters the layout cannot type are skipped. At most 2,000 characters are typed at once.
  • The status bar shows the progress. Stop typing ends it.

Scale

  • Fit to Window is the default. The picture follows the window size.
  • Actual Size (100%) shows one remote pixel per screen pixel, also on high-resolution displays. Fixed sizes show scroll bars when the picture is larger than the window.
  • Zoom In and Zoom Out step from the current size.
  • The shortcuts use Ctrl on every system. They work when the focus is not in the remote picture, because there every key goes to the device.
  • The size applies to this window and is not saved. Full screen always fits.
  • Reverse Mouse Wheel turns the scroll direction around. OpenLAMT saves it for each favorite.

Screenshot

Screenshot saves the remote screen as a PNG file in its own resolution, without the toolbar. It works once KVM shows a picture. The name looks like openlamt-Lab-Server-2026-11-23-101412.png.

With a folder set under Screenshots and recordings, the file goes there at once. Without one, OpenLAMT asks where to save it. The status bar shows “Screenshot saved: …” or the reason it failed. OpenLAMT never overwrites a file in the folder: it adds -2, -3 and so on.

Record

Record records the remote screen as a video. The button turns into a red Stop, and the status bar shows the time and size, for example “REC 02:14 · 18 MB”.

  • The video is a Motion-JPEG AVI file at 10 frames per second. VLC and the players of Windows and macOS play it.
  • The recording stops when you click Stop, when KVM ends and when you close the window. OpenLAMT waits until the file is complete before it quits.
  • A recording stops by itself shortly before 2 GB and says so.
  • The file name and the folder follow the same rules as screenshots, with .avi.

Full screen

Full Screen fills the screen with the remote picture. A small bar at the top offers KVM and Console, Exit Full Screen, Ctrl+Alt+Del, Type Clipboard, Screenshot and Record.

Serial console (SOL)

Console shows the serial console of the device over Serial over LAN (SOL). Use it for systems with a text console on the serial port, for example a Linux server with console=ttyS0, or a BIOS with console redirection. Switch between KVM and Console at any time, also in full screen. Type Clipboard works in the console too.

If SOL is turned off on the device, OpenLAMT asks Enable Serial over LAN?. The setting stays on until you turn it off on the Settings page.

Media (IDE-R)

Media mounts an ISO image on the device as a CD drive. The device sees it like a real drive, even before an operating system starts. Use it to install an operating system, run a firmware update or bring tools and drivers to the device.

  • Mount ISO… mounts an ISO file (CD or DVD). Floppy and disk images (.img) do not work.
  • Mount Folder… turns a folder into a temporary ISO first and mounts it, read only. Each file must be smaller than 4 GB. Large folders take a moment to prepare. The device can boot from a folder over UEFI if it holds EFI/BOOT/BOOTX64.EFI.
  • Boot from ISO on next start makes the next start of the device boot from the image, once.
  • Restart from ISO… restarts the device now and boots once from the image. After that it boots from its own drive again.
  • Unmount removes the image. Closing the window with an image mounted asks first, because an installation running from it would fail.

The status bar shows the transfer rate. While an image is mounted, the device also shows an empty floppy drive. That is how AMT media redirection works.

If media redirection is turned off on the device, OpenLAMT asks Enable media redirection?. On macOS and Windows, OpenLAMT uses the file dialog of the system. On Linux it shows its own.
