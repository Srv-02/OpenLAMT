App settings and updates

These settings belong to OpenLAMT on your computer. They change nothing on your devices. The AMT settings of a device are on its Settings page.

The settings dialog

Click the sliders symbol next to Quick Connect at the bottom of the sidebar. Changes apply when you click Save. Cancel drops them.

General

Language
English or German. System follows your computer. The language changes the next time OpenLAMT starts.
Appearance
Light, Dark or System. System follows your computer, also while OpenLAMT runs.
Color blind mode
Status colors that stay distinct with red-green color blindness, for example the power dots of the favorites.

Updates

With Check for updates on, OpenLAMT asks GitHub at each start whether a newer release exists. Check Now asks right away, also when the switch is off. The row then says “Checking…”, then shows the result: the latest version in green, or the reason in red, for example “GitHub did not answer. Try again later.” A newer version opens the update window.

The request carries no account, token or data about your devices. GitHub sees your IP address.

The update window

The window shows the first lines of the release notes. Update downloads the new version and checks it against the SHA-256 checksum GitHub states. Later closes the window, also during the download. Then OpenLAMT quits the normal way (open KVM sessions ask first) and hands over to your system:

SystemWhat Update does
macOSOpens the new disk image in the Finder and quits. Drag the new app onto the old one.
WindowsReplaces OpenLAMT.exe and starts the new version. In a folder only an administrator may write to, such as Program Files, Windows asks for permission first. The old file stays as OpenLAMT.exe.old until the new version deletes it.
Linux (.deb)Saves the package in ~/Downloads and opens it from there in your software installer, then quits. If a file of that name exists, the new one gets a number, for example OpenLAMT-1.3.0-linux-x64 (1).deb; nothing is overwritten.
Linux (AppImage)Downloads the new AppImage. Show in Folder shows it; replace the old file yourself.

If a step fails, for example because you declined the Windows permission prompt, the package stays in ~/Downloads and the window says how to install it yourself. If the download does not match its checksum or breaks off, Update failed says so and nothing is installed. Try Again starts over.

Devices

Poll interval
How often OpenLAMT reads the power state of your favorites and of open devices, in seconds (1 to 3600). The default is 10.

Remote screen

KVM quality
High (65,536 colors) or Low (256 colors) for every device without its own choice. Low needs less bandwidth.
KVM auto-connect
Connects the remote screen as soon as a device window opens. A favorite can override it.
Disconnect KVM without input after
Ends a remote screen session after this many minutes without keyboard or mouse input, or Never. The default is 30 minutes. AMT allows one KVM session per device, so a forgotten window would block others.
Type clipboard layout
The keyboard layout Type Clipboard uses on the device. Automatic (system language) picks the layout of your system language. A favorite can override it.
Screenshots and recordings
The folder for screenshots and recordings. Choose… sets it, clears it. Without a folder, OpenLAMT asks for a file name each time.

Data

Configuration
Export… and Import… move favorites and settings as a file. See Export and import.
Hidden messages
Reset Warnings shows every message again that you hid with “Don’t show again”.

About and support

About & Credits shows the version and the third-party libraries with their licenses. Support shows ways to help the project, such as a star on GitHub or a coffee. OpenLAMT is free and open source.
