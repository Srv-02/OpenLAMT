- Your AI agent can now record a device's screen as a video and save screenshots as files, so you can check later what it did
- Optionally, OpenLAMT records every screen session of an AI agent by itself, and the agent cannot switch that off
- A recording goes on across restarts of the device and never turns features on or asks the person at the device for a code by itself
- When a recording shows a still picture, for example during a restart, its result says when and why

## Notes
- To record every screen session, set "capture": {"record_always": true} in the openlamt-mcp config. "capture": {"folder": "..."} chooses where recordings go; without it they go to a folder "OpenLAMT" in your home folder.
- Recordings are AVI files that VLC and the standard players of Windows and macOS play without extra codecs.
- The builds are not code-signed. macOS and Windows warn on the first launch; the README explains how to open the app anyway.
