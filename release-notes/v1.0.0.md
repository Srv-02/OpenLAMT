- First public release of OpenLAMT, a native desktop client for Intel AMT on macOS, Windows and Linux
- Switch devices on and off, reset them, power cycle them, shut them down gracefully or reboot them into the BIOS
- Remote screen, keyboard and mouse (KVM), including typing the clipboard in 16 keyboard layouts
- Keep devices as favorites and see their power status at a glance; passwords stay in the system keychain
- TLS with certificate pinning on first use
- Light, dark or system appearance, a color blind mode, English or German, and an update check at start

## Notes
- The builds are not code-signed. macOS and Windows warn on the first launch; the README explains how to open the app anyway.
