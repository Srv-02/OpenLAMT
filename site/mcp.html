MCP server (openlamt-mcp)

openlamt-mcp lets an AI agent use your OpenLAMT favorites: read status and logs, control power, look at the screen and type. It runs on your computer and opens no network port.

What it is

MCP (Model Context Protocol) is a standard way for AI apps to call tools. Claude Desktop, Claude Code and other MCP clients can start openlamt-mcp and talk to it over standard input and output. The agent then sees tools such as list_devices or power_action.

openlamt-mcp is a separate program next to the app. It is not part of the release downloads yet. Build it from the source with Go (no C compiler needed):

go build -o openlamt-mcp ./cmd/openlamt-mcp

Then add it to your MCP client:

{"mcpServers": {"openlamt": {"command": "/path/to/openlamt-mcp"}}}

Devices, passwords and TLS

  • The agent sees your OpenLAMT favorites by their names. It cannot add a host, a user name or a password.
  • Passwords come from the system keychain. Save the password in the app first. Passwords never pass through the MCP connection and never appear in answers or logs.
  • A TLS device works only after you connected once with the app and trusted its certificate. The MCP server never trusts a new certificate.
  • Devices without TLS work, with a warning in each answer.

Tools

ToolWhat it doesGroup
list_devicesLists the allowed favorites. Makes no connection.read
device_statusPower state, AMT version, control mode, TLS.read
hardware_infoSystem, board, BIOS, processors, memory, drives.read
event_log, audit_logLog entries, filtered by time, severity or text.read
power_actionPower on, off, reset, power cycle, shut down. The same rules as the Power menu.power_boot, destructive
boot_to_biosRestarts into the BIOS setup.power_boot, destructive
kvm_connect, kvm_disconnectOpens or closes the remote screen session of a device.read
kvm_screenshotThe screen as an image sized for AI models: at most 1280 pixels on the longest side, JPEG by default.read
kvm_send_keysPresses keys and combinations such as Ctrl+Alt+Delete.kvm_input
kvm_mouseMoves, clicks and scrolls at a point of the last screenshot.kvm_input
kvm_type_textTypes text in the keyboard layout of the favorite.kvm_input

destructive covers every power action except power on. Power off, power cycle and shutdown close an open KVM session first, because AMT refuses them while KVM is open.

AMT allows one KVM session per device. While the agent holds it, the app cannot connect KVM to that device, and the other way round. The session closes with kvm_disconnect, after five minutes without a call, or when the MCP client stops the server.

If a device asks for user consent, the agent must ask a person at the device for the six-digit code and pass it as consent_code.

Limit what the agent may do

Without a config file, everything is allowed.Every favorite and every action, without confirmation. Write a config file before you hand your devices to an agent you do not fully trust.

The config file is openlamt-mcp.json next to favorites.json in your configuration folder, or the file given with --config <path>. Each key you leave out keeps its default. An unknown key stops the server, so a typo cannot leave everything open.

{
  "read_only": false,
  "allowed_devices": [],
  "tool_groups": {"read": true, "power_boot": true, "media": true, "kvm_input": true,
                  "settings": true, "users": true, "destructive": true},
  "require_client_confirmation": false,
  "action_log": {"enabled": true, "path": ""},
  "kvm": {"idle_timeout_seconds": 300, "screenshot_max_width": 1280, "screenshot_max_height": 1280,
          "screenshot_format": "jpeg", "screenshot_jpeg_quality": 80}
}
read_only
Leaves only the read tools, the screenshot included.
allowed_devices
Favorite names the agent may use. Empty means all.
tool_groups
Switches groups of tools off. A tool of a disabled group does not exist for the agent.
require_client_confirmation
Asks you in the MCP client before each power action and each key, mouse or typing call. The question shows every key and the text to type, with each line break (an Enter press) shown as ⏎. If the agent marks a single line as secret, the question says that the agent chose to hide it. A client that cannot ask gets a refusal.
action_log
Writes one line per tool call to openlamt-mcp-actions.log next to the config file, or to path. It holds keys and mouse actions, but never typed text or a consent code.
kvm
The idle timeout of a KVM session (0 keeps it open until the server stops) and the default size, format (jpeg or png) and quality of screenshots. The agent may ask for another size or format per call.

A good start for a helper agent that only looks:

{"read_only": true, "allowed_devices": ["Lab-Server"]}
