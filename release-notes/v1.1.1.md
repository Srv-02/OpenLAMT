- Mount an ISO file or a folder as a CD drive on a device and start the device from it
- Manage a device in a sidebar or its own window: see its hardware, change AMT settings and manage user accounts
- Read the event and audit logs of a device, filter them and open any entry for its details
- Open the text console of a device over Serial over LAN and switch between it and the remote screen, also in full screen
- Changes that can lock you out of a device, such as a new admin password or network address, ask for confirmation and name the device
- On macOS and Windows, you choose ISO files and folders in the system's own file dialog

## Notes
- Mounting a folder first creates a temporary ISO image on your computer. It is deleted when you unmount. A folder that contains a file of 4 GB or more cannot be mounted.
- A mounted folder can start a UEFI device if it contains EFI/BOOT/BOOTX64.EFI.
- While an image is mounted, the device also shows an empty floppy drive. This is how Intel AMT media redirection works.
- The builds are not code-signed. macOS and Windows warn on the first launch; the README explains how to open the app anyway.
