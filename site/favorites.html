Favorites, Quick Connect and network scan

The main window keeps your devices. Save each one as a favorite, find new ones with a network scan, and take your list to another computer.

Favorites

The sidebar lists your favorites. A dot shows the power state of each device. OpenLAMT checks it at start and then at the poll interval.

DotMeaning
Powered on
Standby: the device sleeps or hibernates
Powered off
Unknown: the device did not answer, or the account may not read the power state

OpenLAMT reads the state in the background only for favorites with TLS, a saved password and a trusted certificate. Other favorites keep the grey ring until you connect. A password the device rejected is not tried again until you change it, so a stale password cannot lock the AMT account.

With Color blind mode the dots use colors that stay distinct with red-green color blindness.

  • Connect: select a favorite and click Connect, or double-click it. The device window opens.
  • Search: type in Search above the list. It matches name and host.
  • Edit , duplicate and delete sit above the details of the chosen favorite.

What a favorite holds

Host/IP
The host name or IPv4 address of the AMT interface. No port, no IPv6.
Name
The name in the sidebar. Empty means the host is shown.
Username and Password
The AMT account OpenLAMT signs in with. The password goes into the system keychain when Save password in keychain is on.
Use TLS
Encrypts the connection. See TLS and certificate pinning.
Keyboard
Under Advanced. The keyboard layout of the remote system, used by Type Clipboard. Default follows the app setting.
KVM quality
High (65,536 colors) or Low (256 colors) for this device. Default follows the app setting.
KVM auto-connect
On, Off or Default. With On, the remote screen connects as soon as the device window opens.
Reset fingerprint
Only while you edit. Forgets the trusted certificate, so the next connection asks again.

The device window also stores Reverse Mouse Wheel for each favorite.

While a device window is open, host and username of its favorite are locked: “Close the device window to change host and username.”

Delete a favorite

The dialog Delete Lab-Server? removes the favorite and its trusted certificate from OpenLAMT. Keep Also delete the saved password from the keychain ticked to remove the password as well. Nothing changes on the device.

Quick Connect

Quick Connect at the bottom of the sidebar opens an empty form. Use it for a device you need once. Fill in Host/IP, Username and Password, then click Connect. Click Save as favorite to keep it. Getting started shows the form.

Scan the network

The scan finds Intel AMT devices in an address range. Open it with the radar symbol at the bottom of the sidebar, or with Scan Network… when you have no favorites yet.

  1. Check the Address range. OpenLAMT fills in the network of your computer. Enter a network such as 192.0.2.0/24 or a range such as 192.0.2.10-192.0.2.80.
  2. Click Scan. Devices appear while the scan runs. Stop ends it early and keeps the list.
  3. Tick the devices you want and click Add 2 Favorites (the number follows your choice).

What the columns mean

Intel AMT
The AMT version the device reports without a login, or “unknown”.
Connection
“TLS” when port 16993 is open, “No TLS” when only 16992 is open. “Ports closed” means the device answered on UDP port 623 as a DASH management device, but its AMT ports are closed. AMT is then often not activated (“Not activated?”). You can still add it. Other management controllers that answer on port 623, such as IPMI BMCs of servers, are not listed.

New favorites get the DNS name or the address as name, the user admin, TLS when port 16993 is open, and no password. OpenLAMT asks for the password on the first connection.

The scan only reads. It sends a presence ping on UDP port 623 and checks TCP ports 16992 and 16993. One run covers at most 4,096 addresses (a /20). Scan larger networks in parts.

No devices found? The dialog lists the usual reasons: AMT is off or not activated, a firewall blocks ports 623, 16992 or 16993, or the devices are in another network.

Export and import the configuration

Move your favorites and settings to another computer, or keep a backup. Both buttons are in Settings, section Data, row Configuration.

Export

Export… asks what to include, then opens the save dialog of your system with a name like openlamt-config-2026-11-23.json.

  • Favorites: name, host, user name, TLS and the per-device options.
  • Settings: the app settings.
  • Pinned certificate fingerprints: the other computer then trusts these devices without asking. Turn it off to confirm each certificate again on the first connection.

Passwords are never exported. They stay in the keychain of this computer.

Import

Import… opens a file, checks it and shows a preview first. Nothing changes before you click Import.

  • An import only adds. A favorite with the same host and the same user name as an existing one is skipped and named in the preview. A second login on a known host, with another user name, is added as a new favorite.
  • The settings change only when you tick Also apply settings.
  • Imported favorites have no password. OpenLAMT asks on the first connection.
  • An imported fingerprint never replaces one this computer already trusts. OpenLAMT then names the favorites where the file holds a different certificate.

If the file cannot be used, the dialog Cannot import this file says why: it is not an OpenLAMT configuration, it is damaged (with the line number), or a newer OpenLAMT made it.
